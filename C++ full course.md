# 🏁 Introduction

**C++** is one of the most popular programming language
in the world.
It is used extensively in all domains of
technology where there is need for low-level control, memory management
and speed such as Gaming, web browsers, Kernel, Operating system, and so on.

**C++** is a high-level `statically-typed` and `compiled` language.

> Being `statically-typed` means that the data type of variable must be provided at the time of initiation and that data type can't be changed. You'll talk more on this when we'll learn about `variables and data types`

C++ is a `compiled` language it means it needs a compiler that would convert the C++ program into a machine executable file.

## How C++ works?

Let's look at the diagram to better understand how C++ actually work.

![C++ working flow](C++%20works.svg)

`Compiler` is a software that convert C++ source code into executable file like `.exe` in windows. Two most popular C++ compilers are GCC (GNU Compiler Collection) and Clang (LLVM).

**_C++ source code_** or **_program_** are just simple text files but with `.cpp` or `.h` extension instead of `.txt`, we'll learn more about this as we move further.

`Executable file` is a machine dependent file that can be run only on that particular machine. For instance, if you use compiler on windows to convert C++ file then it would create a `.exe` file and then you can run this `.exe` file directly by double-clicking it. But in linux or mac, the executable file doesn't has any extension.

> NOTE: C++ code itself is platform independent, it means you can take your C++ program and run it on any computer but you'll have to compile your program on that computer.

### Setting up environment

In order to write C++ program we need

1. IDE, which stands for Integrated Development Environment
2. Compiler

#### Installing IDE

IDE is just a text editor that has cool look and extremely cool features.

We can write our C++ program in text editors like Notepad as well but an IDE make it really easy and enjoyable to write code. It actually understand C++ so it gives suggestions, helps to figure out our mistakes and make programming really enjoyable.

One of the most popular IDE is `Visual Studio Code` or `VS code` for short, we'll be using this in this course.

You can install VS code by it's official website. But if you need any help, this video can guide you.

#### Installing Compiler

As said earlier, compiler is a special software that can convert C++ program into executable files that we can run.

There are many compilers available but two main ones are:

1. GCC (GNU Compiler Collection)
2. Clang (LLVM)

We'll go with GCC compiler with this course.

You can install GCC on your computer using it's official website. But in case you need any help this video would help you in installing it.
